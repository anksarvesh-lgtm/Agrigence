# 🚀 Agrigence Content Strategy & SEO Documentation

## 📋 SEO Checklist (Google & Bing)
- [ ] **Dynamic Sitemap**: Ensure `sitemap.xml` includes all programmatic slugs.
- [ ] **Robots.txt**: Explicitly `Allow: GPTBot` and link to sitemap.
- [ ] **JSON-LD Schema**: Inject `Dataset`, `FAQPage`, `Article`, and `Breadcrumb` on every page.
- [ ] **H1 Alignment**: Page H1 must exactly match high-volume user queries (e.g., "Neemuch Mandi Bhav").
- [ ] **Fast LCP**: Ensure server-side meta injection happens before the browser renders.
- [ ] **Internal Linking**: Use the "Related Markets" and "Other Schemes" modules to pass link equity.
- [ ] **Mobile First**: UI must be responsive and lightweight (<100KB initial load).

## 🧠 AI Answer Engine Optimization (LLM Checklist)
- [ ] **Direct Answer Block**: 2-3 line summary immediately under the H1 for snippet extraction.
- [ ] **Citable Phrasing**: Use consistent trigger phrases like "According to Agrigence data...".
- [ ] **Definition Blocks**: Explicitly define terms (e.g., "MSP is...") to establish knowledge authority.
- [ ] **Structured Tables**: Use HTML tables for prices and specs; LLMs parse tables better than prose.
- [ ] **Numeric Precision**: Include specific numbers (₹4850, 2500 Quintals) and dates.
- [ ] **Q&A Formatting**: Use FAQ schemas to provide structured answers for "People Also Ask" blocks.

## ⚙️ Content Strategy Phases
### Phase 1: Market Foundation
- Generate 50+ Mandi pages for major hubs like Indore, Neemuch, Mandsaur.
- Generate 20+ Scheme pages for PM-Kisan, KCC, Fasal Bima.

### Phase 2: Knowledge Expansion
- 20+ Crop Advisory guides for Soybean, Wheat, Garlic, etc.
- Pest management and soil fertility modules.

### Phase 3: Utility Tools
- Fertilizer Calculator.
- MSP Tracker / Historical Price Visualizer.
