## 2024-05-18 - [Add Authorization to Admin Blob Storage Endpoints]
**Vulnerability:** Admin blob storage management endpoints and test endpoints (`/api/admin/blob/upload`, `/api/admin/blob/delete`, `/api/admin/generate-daily-blog`, `/api/admin/trigger-mandi-update`) were missing authentication/authorization checks. While they were grouped under `/admin`, they did not enforce authorization, meaning any unauthenticated user could upload or delete blobs, or trigger system actions like blog generation, which could lead to arbitrary file upload, data loss, storage quota exhaustion, and Denial of Service.
**Learning:** In Express.js applications, merely prefixing routes with `/admin` does not provide security. Middleware checks for authentication and authorization must be explicitly applied to sensitive routes.
**Prevention:** Always verify that routes ending up modifying state or exposing sensitive functionality have an explicit middleware implementing authorization applied to them.
