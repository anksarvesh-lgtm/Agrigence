## 2024-05-18 - Missing Authentication on Admin Endpoints\n**Vulnerability:** Critical administrative endpoints (`/api/admin/blob/upload`, `/api/admin/blob/delete`, `/api/admin/generate-daily-blog`, `/api/admin/trigger-mandi-update`) lacked authentication checks in `server.ts`. This allowed unauthorized users to upload/delete files and trigger background jobs.\n**Learning:** In express routes, never rely on frontend hiding of features for security. All administrative or sensitive API routes must explicitly implement authentication and authorization checks at the server level.\n**Prevention:** Implement a standard authentication middleware (like `requireAdminAuth`) and apply it globally to an admin router or consistently to all `/api/admin/*` routes. Regularly audit all route definitions for missing authentication middleware.
