## 2024-06-12 - Missing Authentication on Administrative API Endpoints
**Vulnerability:** Key administrative backend endpoints (e.g., `/api/admin/blob/upload`, `/api/admin/blob/delete`, `/api/admin/generate-daily-blog`, `/api/admin/trigger-mandi-update`) were publicly accessible without any authentication or authorization checks.
**Learning:** Even internal or "testing" endpoints in a Node.js Express server must be protected, as they are exposed to the public internet once deployed. Administrative tasks that modify state (like file uploads/deletions or triggering background jobs) without authentication can lead to Denial of Service (DoS) or arbitrary file hosting/deletion (in this case via Vercel Blob).
**Prevention:** Implement a standard authentication middleware (e.g., checking an `x-admin-key` header against a secure environment variable like `ADMIN_API_KEY`) and apply it globally to all `/api/admin/*` routes or directly on the administrative route handlers. Never deploy administrative endpoints to production without adequate protection.
